Common Management Options

You can manage this extension's core behavior natively through your browser's extension settings page.

On/Off Toggle

You can completely disable the extension without deleting it. This instantly stops all location overriding and background processes.

Allow in Incognito

By default, extensions cannot run in private browsing windows. If you use the attendance portal in Incognito mode, you must explicitly grant this permission in the extension settings.

Site Access

Controls whether the extension can read and change data. Currently, it is heavily restricted to only operate on specific target URLs (https://portal.university.edu/*) for maximum privacy and safety.

Pin / Unpin

Click the puzzle icon in your browser toolbar to pin this extension. This allows you to quickly open the popup to drag the map and update coordinates.

Remove

Completely uninstalls the extension and deletes all saved preferences and custom coordinates from your local storage.

System Architecture & Explanation

This extension operates by silently overriding the standard web APIs that websites use to ask for your physical location.

1. The Injection Bridge

Modern browsers isolate extension scripts (ISOLATED world) from the website's scripts (MAIN world) for security. To successfully trick a website, this extension injects a tiny script directly into the MAIN world before the page even finishes loading (document_start). This script overwrites the native navigator.geolocation.getCurrentPosition and watchPosition functions.

2. Coordinate Spoofing & Drift

When the attendance portal asks for your location, the overridden function intercepts the request. Instead of asking your hardware GPS, it immediately responds with the exact Latitude and Longitude you selected in the popup. To make the spoof appear legitimate, it also applies a slight random "accuracy drift" (e.g. 15-25 meters) so the data resembles a real mobile phone GPS sensor.

3. Real-time Communication

The popup uses the chrome.storage API. When you drag the map pin in the popup, the new coordinates are saved instantly. A background service worker detects this change and broadcasts it directly to any open attendance tabs, allowing you to "walk" around the map without reloading the portal.

Risks & Disclaimers

Disclaimer: This extension is provided for educational, research, and privacy purposes. You are solely responsible for how you use it.
  • Academic Integrity: Spoofing your location to submit attendance when you are not physically present may violate university policies or academic integrity codes. Misuse can lead to severe disciplinary action.
  • IP Address Detection: This extension only overrides browser GPS coordinates (frontend). It does not change your IP address. If the server checks whether your IP address belongs to the campus network, they will know you are off-campus regardless of your GPS coordinates.
  • VPN Usage: To mitigate IP detection, you should use the official OpenVPN campus profile alongside this extension. However, be aware that system administrators can easily identify VPN IP pools.
  • Telemetry & Timing: Sophisticated anti-cheat systems can detect spoofing by measuring response times (real GPS takes a few seconds to lock on, whereas spoofed GPS responds instantly) or by looking for missing browser sensor telemetry.

Thorough Q&A

Q: I set my location, but the website still says I'm far away. Why?

A: The website might have cached your previous location, or it might be relying on your IP Address rather than GPS. Try hard-refreshing the page (Ctrl+F5). If that fails, ensure the extension toggle is strictly set to "Active" in the popup.

Q: Do I need a VPN to use this?

A: For frontend GPS bypass, no. However, if the attendance portal requires you to be connected to the campus Wi-Fi network to submit, you will need to use a VPN (like OpenVPN Connect with your campus profile) to route your traffic through the university servers.

Q: Can the administrators detect this extension?

A: Websites cannot natively see what extensions you have installed due to browser sandboxing. However, they can infer spoofing if your GPS coordinates perfectly match the center of a building with exactly 25.0 meters of accuracy, or if you jump 10 miles in 2 seconds. The extension tries to mitigate this by adding slight randomness.

Q: Why did I get a timeout error when taking attendance?

A: Sometimes the portal's backend server is overloaded, or your VPN connection dropped packets. The extension answers the GPS request instantly, so timeouts are almost always an issue with your network or the target server, not the spoofer.

Q: Does this work on my phone?

A: Standard Chrome for Android/iOS does not support extensions. You would need a browser that supports mobile extensions (like Kiwi Browser or Firefox Nightly for Android), but results may vary heavily based on the OS-level location permissions.
