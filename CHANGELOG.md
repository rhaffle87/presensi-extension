## [1.0.0] - 2026-09-02

### Added
- Initial public release of the GPS Spoofer extension.
- Chrome manifest v3 configuration.
- Global toggle switch to enable/disable spoofing.
- Interactive Leaflet.js map for visualizing coordinate targets.
- Quick Select grid with campus presets (Tower 1, Tower 2, Koridor C).
- Manual coordinate entry.
- Build system with JavaScript obfuscation for the content script (`build.js`).
- Basic `.github/workflows/release.yml` GitHub Actions pipeline for automated zip deployment.
- **Cybersecurity Analysis:** Created `vulnerables.md` and added auditing and sensor validation strategies focusing on the institutional system weaknesses.
